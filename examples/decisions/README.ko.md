# 기존 스킬 유지가 결과가 되는 경우

[English](README.md)

## 실제 유지 결정: 승인한 형식 보존

[회의록 기록](../maintenance-records.ko.md)에서는 evolve 변경 대부분이 승인한 형식에서 벗어나 되돌려졌습니다. 기존 형식을 유지하고 별개의 재전사 규칙은 남겼습니다. 전체 무변경이 아닌 부분 되돌림이며 통제된 벤치마크도 아닙니다.

## 재현 가능한 예시 판단: 회귀 기각

`python3 examples/inventory/check.py`를 실행하세요. 누락 출력은 합계가 맞지만 재고 0인 행이 빠져 R1에서 실패합니다. 해당 출력은 기각합니다. 짧아진 지침 후보도 실제 동작이 미검증이므로 따로 둡니다. [전체 재고 예제](../inventory/README.ko.md)에서 확인할 수 있습니다.

## 작성된 무변경 시나리오: 서비스 장애

[status-case.json](status-case.json)에 지침, 가상의 정상 응답과 HTTP 503, 각각의 출력 예시를 담았습니다. 실패 응답은 이미 상태를 확인할 수 없다고 보고하라는 지침을 지킵니다. 재시도·다른 서비스·추측한 상태를 추가할 지침 결함은 관찰되지 않았습니다. 기록한 결정은 스킬을 그대로 두는 것입니다.

실제 에이전트 실행이 아닌 설명용 판단 사례입니다. 예제 검사는 가상 응답과 출력의 대응만 확인하며 에이전트 진단 능력을 입증하지 않습니다. 실제로 시험하려면 [evolve 시나리오 4](../../evals/evolve-scenarios.md)를 새로 실행하고 기록과 결과물을 남기세요. 원인이 불확실하면 보고서에 남깁니다. diff를 만들기 위해 고칠 근거는 되지 않습니다.
