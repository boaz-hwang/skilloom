# refine

기존 스킬 하나를 간결하게 다듬으세요.

[English](README.md) · [스킬 본문](SKILL.md) · [MIT](LICENSE)

스킬 전체와 연결된 자료를 검토해 불필요한 지침을 덜어내고 결과의 필수 조건을 보존합니다. 실행 기록이 없어도 동작합니다.

## 설치

```text
https://github.com/boaz-hwang/skilloom 을 git clone해서 skills/refine을 스킬 디렉터리에 refine으로 설치해줘.
```

## 사용

```text
refine으로 <스킬 이름>의 목적과 필수 조건을 보존하면서 전체 구조와 지침을 다듬어줘.
```

## 동작

1. 원하는 결과와 필수 조건, 연결된 자료를 읽습니다.
2. 삭제부터 검토한 뒤 필요한 부분만 축약·수정·재구성합니다.
3. 변경의 영향에 맞게 검증하고 근거가 있는 정비안만 반영합니다.

한 번에 스킬 하나를 다루는데, 문서가 명확해졌는지와 실제 수행 성능이 좋아졌는지는 따로 보고합니다.
