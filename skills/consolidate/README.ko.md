# consolidate

겹치는 스킬을 하나로 합칩니다. 필수 기능은 그대로 남깁니다.

[English](README.md) · [스킬 본문](SKILL.md) · [MIT](LICENSE)

여러 스킬의 결과물과 필수 조건을 비교해 통합할 후보를 제안하는데, 합치면 더 복잡해지는 역할은 따로 둡니다.

## 설치

```text
https://github.com/boaz-hwang/skilloom 을 git clone해서 skills/consolidate를 스킬 디렉터리에 consolidate로 설치해줘.
```

## 사용

```text
consolidate로 <스킬 폴더>의 중복을 검토하고, 통합안을 나에게 확인받은 뒤 통합해줘.
```

## 동작

1. 결과물·필수 조건·자료·성공 사례를 비교합니다.
2. 어떤 스킬을 어디로 합치고 무엇을 남길지 확인받습니다.
3. 최소 지침으로 통합본을 만들고 각 원본의 기능을 검증합니다.
4. 승인된 통합안을 적용하고 중복은 정리합니다. 원본은 그대로 보존해 둡니다.

기능 보존을 확인하지 못하면 원본을 유지하고 후보만 따로 남깁니다. 통합할 대상이 없다는 판단도 결과로 보고합니다.
