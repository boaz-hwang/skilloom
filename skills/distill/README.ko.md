# distill

방금 끝낸 업무를 스킬로 남기세요.

[English](README.md) · [스킬 본문](SKILL.md) · [MIT](LICENSE)

호출하면 그 업무를 대신 수행하는 스킬이 생깁니다. 완료한 업무의 결과와 피드백을 읽어 재현에 필수인 조건만 추출하며 실패했던 경로나 우회는 담지 않습니다.

## 설치

```text
https://github.com/boaz-hwang/skilloom 을 git clone해서 skills/distill을 스킬 디렉터리에 distill로 설치해줘.
```

## 사용

```text
distill로 이 업무를 재사용 가능한 스킬로 만들어줘.
```

## 동작

1. 이름 후보 3개 중 하나를 추천하고 결과물 한 줄 설명을 확인받습니다.
2. 최소한의 핵심 과정을 제안하고 수정한 과정은 다시 확인받습니다.
3. 간결한 지침과 필요한 자료, 검증 코드, 사람 평가 질문을 만듭니다.

업무 결과에 만족했다면 그 세션에서 바로 호출하세요.
